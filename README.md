# Plan & Model

Public pages and the Mac helper for **Plan & Model**, an iPhone and iPad app that scans rooms with
LiDAR and saves floor plans, drawings and 3D files in iCloud Drive for Claude, Blender and FreeCAD.

- Website: https://davidhoppestad.github.io/plan-and-model/
- `lidarscan-mcp/`: a read-only MCP server that lets Claude Desktop and Claude Code read your
  scans on your Mac. Install it from the [latest release](https://github.com/DavidHoppestad/plan-and-model/releases).

The app itself is developed in a separate private repository; this repository is generated from
it, so changes made here directly are overwritten.
